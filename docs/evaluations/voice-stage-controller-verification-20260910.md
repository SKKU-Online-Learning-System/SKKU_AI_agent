# 소프트맥스 단계 제어 검증 — 2026-09-10

## 후속 수정: 중단 의사와 정답 판정 분리

아래 기존 실험 이후, 단일 평가 호출의 출력을 `intent: continue | pause`와
`verdict: correct | incorrect | insufficient`로 분리했다.
코드는 intent가 pause이면 정답 처리보다 먼저 중단하며, 단계를 이동하거나 이해 근거를 저장하지 않는다.
학생 표현별 키워드 분기는 추가하지 않았다. 모델·운영 경로는 변경하지 않았다.

기존 46턴과 추가 경계 사례 8턴(오답+중단, 간접 중단, 중단 부정, 타인의 중단 발화 인용)을
실제 Qwen/Qwen3.5-9B로 실행하여 **54/54턴 통과**했다.
10개 합성 시나리오를 각 2회 실행했으며, 정답 판정과 중단 의사, 전후 단계, 중단 상태를 함께 확인했다.
기존에 실패한 “각각 0.5인데 오늘은 그만하자”도 두 번 모두 정답이면서 중단으로 판정했다.
평가 호출과 코드 처리의 중앙 지연은 1,564ms다. 전체 음성 응답 지연은 아니며,
이전 실행과 사례 구성이 달라 지연 증감의 인과 비교는 하지 않는다.

[분리 후 원시 요청·출력](voice-stage-controller-split-intent-20260910.jsonl)

현재 스크립트의 결과 검사기는 확장된 54턴과 새 스키마를 검증한다.

Ponytail 원칙으로 추가 모델 호출이나 새 의존성 없이 기존 시제품만 수정했다.
이는 제한된 단계 제어 검증의 완료다. 고정 힌트 반복과 자유 대화 생성은 여전히 미해결이며,
모델의 의도 오판 가능성까지 제거한 것은 아니다. 운영 적용 및 자연스러운 음성 대화 개선 완료로 해석하지 않는다.

## 결론

모델이 학생 답변을 평가하고 코드가 학습 단계를 전환하는 제한된 시제품을 구현했다.
최종 시험은 46턴 중 45턴이 예상 판정·단계·중단 상태를 모두 만족했다.
정답과 중단 요청이 함께 있는 발화에서 중단을 무시한 실패가 남아 운영에는 적용하지 않았다.
이 결과는 자연스러운 자유 대화의 해결이나 모델 성능 문제가 없다는 증거가 아니다.

## 구현 범위

- 기존 LLMService와 Qwen/Qwen3.5-9B 음성 프로필 사용. 모델 교체·학습·운영 설정 변경 없음.
- 같은 입력의 확률 → 같은 확률인 이유 → 개념 요약의 세 단계.
- 모델은 correct / incorrect / insufficient / pause와 정답 근거 인용만 반환한다.
- 코드가 한 단계씩 이동하며, 정답 근거는 현재 학생 발화에 실제 존재해야 한다.
- 학생 표현별 문자열 분기는 없다. JSON 문자열로 감싼 근거는 디코딩 후 원문 일치를 재검증한다.
- 질문·힌트·마무리는 고정 문장이다. 판단과 자유 발화 생성을 분리한 실험이며, 운영 음성 에이전트 통합은 아니다.

| 중단 우선 평가 지침 추가 후 같은 46턴 | 45/46 | 같은 결합 사례에서 1회 중단 무시 |

최종 실행에서 나머지 44턴은 모두 통과했다. 망설임·단순 수긍에는 현재 단계를 유지하고,
정답의 여러 표현은 받아들였으며, 오답은 유지하고 단독 중단 요청은 중단했다.
실패 발화는 “각각 0.5인데 오늘은 그만하자”다. 두 번째 반복에서 pause 대신 correct를 반환해 다음 단계로 갔다.
최종 중앙 지연은 1,234ms이며 **평가 호출과 코드 처리만** 포함한다.
ASR·TTS·검색·자유 답변 생성이 제외되어 기존 전체 음성 에이전트 지연과 직접 비교하면 안 된다.

## 해석과 다음 수정 지점

코드는 모델이 판정한 결과에 따른 단계 이동을 제한하지만, 의미상 잘못된 판정 자체는 막지 못한다.
원문 인용이 있다고 그 판정이 옳다는 뜻도 아니다.
다음 수정 후보는 정답 평가와 계속할 의사를 별도 필드로 분리하고, 중단 의사가 있으면
코드에서 정답 여부와 무관하게 중단하는 방식이다. 이는 아직 구현·검증하지 않았으며,
모델이 중단 의사 자체를 놓치는 위험도 남는다.

Ponytail 원칙으로 범위를 세 단계와 고정 발화로 제한했다.
반복 망설임에 같은 힌트를 반복하는 한계가 있어 자연스러움 개선 완료로 볼 수 없다.
시나리오는 소수의 합성 한국어 발화이며, 전체 대화 이력 대신 현재 목표와 직전 교사 발화만 평가기에 전달한다.
사람 평가, ASR 오류, 다른 개념, 운영 경로와의 비교 검증은 수행하지 않았다.
