# 음성 입력 분리 진단 — 2026-09-10

## 결론

재현 경로에서 최근 대화가 누락되는 결함은 발견하지 못했다. 현재 9B는 직전 질문과 학생 발화를 받아도 모호한 수긍을 정답으로 평가하고, 학습 상태에 맞는 다음 행동을 안정적으로 고르지 못한다. 단순 예시 삭제·정책 축약·자료 경계 표시로는 해결되지 않았다. 따라서 “모델 역량은 관계없고 프롬프트만 문제”라는 결론 역시 근거가 부족하다. 모델, 정책, 도구 출력 제약의 상호작용은 아직 분리되지 않았다.

## 방법

운영 설정 변경 없이 기존 평가 도구와 동일한 Qwen3.5-9B 음성 프로필을 사용했다. 합성 대화만 사용했으며 실제 학생 로그를 읽거나 기록하지 않았다. ASR·DB·RAG 검색·TTS는 시험하지 않았다.

- 3개 사례(망설임, 수긍, 정확한 요약) × 4개 입력 조건 × 2회 = 24회.
- 조건: 기존 입력, 정책의 예시 두 줄 제거, 자료와 발화 이력 경계 설명 추가, 소크라틱 정책만 짧은 정책으로 교체.
- 추가 대조: 망설임 사례에서 자료 제거 또는 마지막 학생 발화만 명시적 도움 요청으로 변경, 각 2회 = 4회.
- 같은 모델·출력 한도·temperature·thinking 설정. 단일 요청씩 실행. 사례와 조건 순서는 고정 시드로 섞었다.
- 공급자 어댑터 진입 직전의 정규화된 system/messages/tools를 원문 JSONL에 저장했다. API 키는 저장하지 않았다. 서버 내부 chat template 처리나 실제 음성 세션과의 일치는 확인하지 않았다.

## 관측

1. 기존 망설임 입력에는 교사의 softmax 질문과 학생의 “그러게”가 모두 포함됐다(3개 메시지). 수긍 사례는 보고된 이전 대화까지 9개 메시지가 보존됐다. 입력 누락보다 해석·행동 선택 실패를 지지한다.
2. 기존 입력과 짧은 정책에서 “그러게”에 부적절한 “맞습니다”가 각각 2/2회 나타났다. 예시 제거와 경계 설명 조건에서는 해당 시작 표현은 사라졌지만, 계산을 요구하거나 더 어려운 예측으로 넘어가 적절한 망설임 대응은 아니었다. 단어가 사라지는 것을 해결로 보지 않는다.
3. 수긍 후 기존 내용 반복은 네 조건 모두에서 남았다. 정확한 요약 뒤 질문 없이 끝내기는 기존과 짧은 정책에서 각각 2/2회였고, 예시 제거와 경계 설명에서는 불필요한 질문이 각각 2/2회 나타났다. 단순화가 일관된 개선은 아니다.
4. 마지막 학생 메시지를 “잘 모르겠어. 힌트를 줘.”로 바꾸면 부적절한 정답 칭찬은 2회 모두 사라졌다. 그러나 안심 표현은 1회뿐이고, 두 응답 모두 답을 설명해 버려 작은 힌트부터 주는 행동은 안정적이지 않았다. 이는 실제 학생 발화를 바꾸자는 제안이 아니라 모호성 대조 실험이다. 이 조건의 system 내 student_question은 원래 “그러게”를 유지했다는 한계가 있다.
5. 자료를 제거하면 두 응답 모두 부적절한 동의가 남고 softmax 계산도 틀렸다. 한 응답은 2/5와 3/5를 softmax 결과로 제시했다. 참고자료를 없애는 처방은 부적절하며, 자료가 사실 정확성에 기여할 가능성을 보여 준다.

## 코드상 추가 제한

`VoiceContext`는 최근 12개 메시지만 보존한다. 따라서 긴 세션에서는 앞선 학습 이력이 사라질 수 있지만, 이번 재현은 그 한도 이내라 현재 실패의 설명은 아니다. 정상 음성 경로는 `_brain_context`를 `think_voice`로 전달하며, 해당 함수가 학생과 교사 메시지를 추가한다. 일반 경로에서 같은 학생 발화를 이중 추가하는 패턴은 확인되지 않았다.

## 다음 분리 실험

짧은 발화의 의미와 다음 교육 행동을 따로 묻는 진단에서 판단 자체가 가능한지 확인하고, 같은 대화로 일반 텍스트 출력과 현재 finish_turn 도구 출력을 비교할 필요가 있다. 이는 두 단계 호출을 운영에 추가하자는 제안이 아니다. 판단 능력과 출력 계약의 영향을 구분하기 위한 오프라인 진단이다. 추가 지연을 유발하는 설계나 키워드 조건문은 추가하지 않았다.
