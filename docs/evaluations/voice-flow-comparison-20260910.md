# 복잡한 흐름과 단일 응답 생성 비교

## 결론

단일 응답 생성은 빨랐지만, 이 시험에서는 잘못된 정답 인정과 후속 질문 누락을 해결하지 못했다.
따라서 복잡성만이 원인이라고 할 수 없으며, 단일 호출로 교체하면 품질도 개선된다는 가설은 지지되지 않았다.
이 결론은 두 구체적 시제품의 비교이며, 모델의 일반적인 능력 한계를 증명하는 것은 아니다.
운영 코드·모델·서버 설정은 변경하지 않았다.

## 방법

같은 Qwen/Qwen3.5-9B 음성 프로필, 같은 서버, 호출당 최대 320토큰을 사용했다.
기존 고정 발화 실행에서 망설임·수긍·모름·정답·이유 답변·오답·중단·정답과 중단 결합의
8개 장면을 추출해 각각 2회, 두 방식으로 실행했다. 총 32개 응답이며 모드별 16개다.
장면과 반복별 실행 순서를 교대했으며 요청은 순차 실행했다.

- complex: 기존 평가 요청 → 원문 근거 검사 및 단계 이동 → 피드백 생성 → 코드 질문 부착.
  중단은 평가 후 고정 문장으로 끝나므로 호출 1회, 나머지는 2회다.
- simple: 실제 역할별 대화 이력·현재 목표·참고 사실·짧은 지도 지침으로 일반 텍스트를 한 번 생성한다.
  평가 판정·근거 인용·코드 단계 전환·질문 부착은 없다. 빈 답과 180자 초과는 오류로 기록한다.

같은 장면의 학생 발화와 원본 이력을 재사용하지만, 모델에 전달하는 표현 방식은 다르다.
complex 평가기는 직전 교사 발화만, 발화기는 최근 8메시지를 받고,
simple은 해당 장면 전체 이력을 역할별 메시지로 받는다.
프롬프트·출력 형식·이력 표현·호출 수가 함께 다른 **두 설계의 비교**이지
호출 수 또는 코드 복잡성 한 요인만 바꾼 인과 실험은 아니다.
기존 시제품 함수 재사용은 Ponytail 원칙에 따른 것으로 새 의존성은 없다.

독립 장면별 응답을 비교하므로 한 방식의 출력 뒤에 다른 질문에 대한 학생 대사를 강제로 이어 넣지 않는다.
이는 실제 자율 다중 턴 수업 시험이나 사람 평가가 아니다.

## 결과

| 항목 | complex | simple |
|---|---:|---:|
| 응답 수 | 16 | 16 |
| 실제 모델 호출 수 | 28 | 16 |
| 완료까지 중앙 지연 | 2,781ms | 903.5ms |
| 요청·형식 오류 | 0 | 0 |
| 정답 뒤 필요한 다음 질문 | 4/4 | 1/4 |
| 중단 요청 후 종료, 즉시 새 질문 없음 | 4/4 | 4/4 |

지연은 평가 및 응답 생성 완료까지로 ASR·TTS·검색을 제외한다. 첫 음성 출력 지연이 아니다.
simple이 더 짧게 답하고 후속 질문을 생략한 경우도 있으므로 같은 기능을 제공하면서
속도만 개선됐다고 해석하면 안 된다. 동시 서버 부하·캐시를 통제하지 않았고 표본도 작다.
형식 통과는 품질 통과를 뜻하지 않는다.

의미적 항목은 전체 32개 출력을 직접 검토했다. 정답 뒤 다음 질문은 수치 정답 후 이유 확인,
이유 정답 후 개념 요약 요청이 있는지를 기준으로 삼았다.
중단 항목은 대화를 실제로 멈추는 응답인지 평가한 것이며, simple의 내부 중단 상태는 존재하지 않는다.

## 대표 출력

- “그러게”, simple 반복 1: “정답입니다. 다음으로, 왜 두 확률이 같은지 그 이유를 설명해 주시겠어요?”
  학생이 답하지 않았는데 정답 인정과 다음 단계 진행이 함께 발생했다. 두 반복 모두 같은 유형의 오류다.
- “각각 0.5겠네”, simple 반복 0: “맞습니다. 두 입력이 같으므로 확률은 각각 0.5가 됩니다.”
  정답 인정 뒤 다음 질문이 없다.
- 이유를 설명한 정답에 simple은 두 반복 모두 인정만 하고 요약을 요청하지 않았다.
- “응”, complex는 두 반복 모두 “정답이 맞아요”라고 했다. 코드 질문 유지가 잘못된 칭찬을 막지는 못했다.
- 정답과 중단을 결합한 simple 반복 1에는 “今天就到此为止”가 섞였다.
  중단 의사는 존중했지만 한국어 음성 품질 문제는 남는다.

결론적으로 complex는 질문 진행을 더 잘 유지했고, simple은 더 빨랐다.
두 방식 모두 자연스러운 학습 대화의 요구를 만족하지 못하므로 운영 교체 근거로 삼지 않는다.
